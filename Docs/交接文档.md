## 一、这是什么

2D 拼图休闲游戏。背篓取石 → 锅里熬煮 → 拖到天空的缺口 → 填满愈合 → 灵气返还，灵气归零则失败。

- **目标平台**：Steam（Windows）、TapTap（Android）、微信/抖音小游戏、iOS
- **目标用户**：儿童与女性玩家为主，Q 版马卡龙风格
- **商业模式**：完全免费、无广告
- **多语言**：简中 / 繁中 / 英文，游戏内切换（自研轻量 L10n，未用官方 Localization 包）

## 四、核心规则（改数值前先读）

- **愈合**：洞口填满即愈合，不校验形状组合。
- **补给**：`InventoryManager.EnsureSupply` 按「各洞剩余空格」切石，留 3 格余量；格数够但没有任何块塞得进时强制重切（`HasAnyPlaceableStone`）。
- **切石**：`ShapeCutter` 贪心 + 最多 30 次重试。目标块数 = `max(maxPieces, 格子数 ÷ 池内最大形状格数)`，避免大洞空转。
- **形状池**：11 种，最大 4 格（5 格形状已移除，它们是废石主要来源）。
- **灵气**：只按 `grid==0` 的未填格扣费；洞闭合返还灵气。
- **无尽模式**：五条难度轴 —— 灵气消耗↑、洞格数↑、补洞间隔↓、锅容量 2→4、旋转概率 0.4→0.9、预煮熟概率 0.4→0。

## 八、开发环境与常用命令

**编辑器**：`D:\develop\Unity\TuanjieEngine\2022.3.62t6`（另有 t16，无 Mac 模块）

**跑测试**：菜单 `MendingtheSky / 跑 EditMode 测试`，结果写 `Temp/editmode_test_results.txt`（编码 UTF-8）。
⚠️ 编辑器处于 Play 暂停态时测试跑不了，先停止 Play。

**切换平台**：`EditorUserBuildSettings.SwitchActiveBuildTarget`，会触发编辑器重载并断开 Codely bridge，重连后 `unity_editor refresh` 即可继续。

**Android 构建**：切到 Android 平台 + IL2CPP（已配置），构建约 4~10 分钟。
⚠️ Gradle 依赖需国内镜像，已配在 `C:\Users\<user>\.gradle\init.gradle`（阿里云 + 官方源兜底）。

**调试热键**（`DebugCheats`）：Q 灵气+20｜T 开关灵气消耗｜空格 新洞+发石｜K 全洞｜L 重开｜I 重发灵石｜J 打印洞形状｜H 取下鼠标处已放置灵石

## 九、踩坑速查

完整版在 `Docs/AI协作规范.md`，这里只列最容易重复踩的：

1. **`sprite.border` 在本引擎被当作矩形像素**，与 ppu 无关。边框之和 > 矩形高度时中间拉伸带塌陷、整条不可见（灵气条就是这么坏的）。小尺寸目标不要用九宫格。
2. **UGUI 的 SpriteSwap 改的是 `Image.overrideSprite`**，不是 `sprite`；**ColorTint 改的是 `CanvasRenderer`**，不是 `Image.color`。只读错字段会误判「状态没生效」。
3. **`Rigidbody2D.simulated=false` 会让碰撞体退出物理查询**，会导致已放置的石头再也拾取不了。冻结用 `bodyType = Kinematic`。
4. **`GameObject.Find` 找不到 inactive 对象**，要用 `Resources.FindObjectsOfTypeAll` 或层级遍历。
5. **单次采样不可信**（音频输出、动画），要多次采样。
6. **Mono 后端在 Android 出不了 ARM64**，设置勾了也会被静默丢弃 —— 必须 IL2CPP。
7. **`CalculateInitialInventory` 内部会调 `ClearAll`**，别把「本局配置」放在 `ClearAll` 里重置，会被开局流程抹掉。
8. **节点初始 inactive 时 `Awake` 不会执行**，直到第一次 `SetActive(true)`。在 `Awake` 里调 `Hide()` 会把刚打开的根节点又关掉（引导就踩过）。

## 十、接手建议

1. **先读 `Docs/架构说明.md`**：一句话架构、启动时序、一次放置的完整调用链、按「我想改 X」查的职责表。
2. **先跑一次测试**，确认 115 条全绿再动代码。
3. **改玩法数值前先看 `Assets/ScriptableObjects/Levels/Level14.asset`**，那里有当前最高难度的参数基线。
4. **UI 改动要用像素级验证**：项目历史上「看起来没变」和「其实已经塌了」很难区分，具体手法见 `Docs/AI协作规范.md` 第 11~15 条。
5. 当前项目**功能已冻结**，重心是发布流程。新需求先确认是否影响上架时间。
