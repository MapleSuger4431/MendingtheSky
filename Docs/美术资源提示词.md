## 目标用户与美术基调

**核心受众：儿童 + 女性玩家；兼顾男性玩家。** 美术基调据此确定：

- **可爱 Q 版**：所有物体圆润饱满、比例呆萌，无尖锐棱角
- **马卡龙色系**：明亮柔和的糖果色，避免大片深色和压抑感
- **治愈梦幻**：祥云、星星、彩虹光晕点缀，温馨不恐怖（天空缺口也不能吓人）
- **男性玩家兼容**：保留魔法冒险感和神话史诗气质（青蓝主调 + 彩虹点缀），避免全粉少女化
- **儿童可读性**：高对比、大色块、轮廓清晰，一眼认出"这是什么"

## 使用备注

1. **生成顺序建议**：灵石方块(9张) → 缺口+边界 → 背景 → 锅/背篓 → UI。前四项就能让原型摆脱占位方块。
2. **同批生成**：同色系资源尽量在同一次会话里连续生成（风格更稳定），或始终复用上面的统一风格锚。
3. **我可以直接生成**：说一声"生成 XX"，我会调 TJGenerators 落地到 Assets 并配置导入设置（消耗平台积分，失败不扣）。
4. 灵气条 `fillAmount` 需要条形贴图本身是"满"状态；渐变色建议从左到右单向过渡，方便 UI 裁切。
5. **儿童向红线**（生成后自查）：无深黑大面积色块、无尖锐恐怖元素、无复杂纹样（饕餮纹已移除）、轮廓能在缩小 50% 后仍清晰可辨；移动端旋转按钮 ≥44px 触点（设计已定）。
6. 男性玩家兼容性自查：主视觉保留青蓝/金色神话调，彩虹和粉色只做点缀不做主色。
7. 微信小游戏包体：1920×1080 背景压成 WebP/高质量 JPG，长边 1280 起步测试效果，发布前按包体预算调整。
8. 占位渲染配色可在 GridVisual Inspector 里直接调亮（`fallbackHoleColor` / `fallbackEdgeColor` 字段），替换正式美术前可先调成柔和紫蓝。
